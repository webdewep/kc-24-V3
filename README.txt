КЛИНИНГ СЕРВИС 24 — КОММЕРЧЕСКАЯ РЕДАКЦИЯ V1

КАК ОТКРЫТЬ
1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте index.html в Chrome или другом современном браузере.
3. Прокручивайте страницу: сперва проходка к дверям и их открытие,
   затем последовательная фотопостановка в одном и том же помещении.

ПЕРВЫЙ ЭКРАН
- Часть 1: плавное приближение к закрытым дверям, распахивание створок,
  проход камеры внутрь, затем полная остановка камеры.
- Часть 2: шесть последовательных состояний той же локации:
  грязное помещение -> вывоз мусора -> поломоечная машина -> мойка окон ->
  очистка поверхностей -> чистое помещение.
- Каждый этап сопровождается отдельным русскоязычным заголовком.
- Вперёд и назад, без автопрокрутки, без видео.
- GSAP ScrollTrigger через CDN, при отсутствии интернета — нативная
  sticky-реализация, привязанная к прокрутке.
- На телефоне проходка короче и сцена показывается шире.
- При включённом предпочтении уменьшенной анимации остаётся
  доступная статичная версия.

СТРУКТУРА
Работы компании, преимущества, процесс, прайс с вкладками, отзывы,
о компании, полезные материалы, SEO, FAQ, заявка и кнопки связи.

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
- Изображения первого экрана и сервисов — демонстрационные/сгенерированные.
  Фотосцена иллюстрирует идею уборки, а не документирует реальный заказ.
- В портфолио шесть работ: офис, склад, торговый центр, поликлиника, ресторан и коттедж.
- В карточках по одному снимку из портфолио компании. Источники указаны в WORKS-SOURCES.json.
- Заголовок и кнопка каждой карточки открывают страницу работы.
- Логотип в шапке стилизован, его надо заменить оригинальным файлом.
- Заявка по умолчанию формирует письмо в почтовом приложении посетителя.
  Для отправки прямо с сайта на PHP-хостинге установите для формы
  data-mode="php", настройте серверную почту и протестируйте send.php.
- Проверить контакты, реквизиты, согласие, политику и все внешние ссылки
  перед запуском на публичном домене.
- SEO canonical задайте после выбора доменного имени лендинга.

ФАЙЛЫ
index.html — разметка, стилизация БЭМ
styles.*.css — адаптивные стили и эффекты
script.*.js — прокрутка, стоп-моушен, формы, табы, меню
send.php — опциональный почтовый обработчик
assets/ — изображения

ПРОКРУТКА ПЕРВОГО ЭКРАНА
- На всём протяжении первого экрана стоит CSS sticky pin, поэтому
  прокрутка управляет только сценой. Разделы после hero становятся видны
  лишь после завершения всех этапов.
- Внешние библиотеки не нужны для самого закрепления: эффект работает
  и без интернета при открытии index.html.
- GSAP ScrollTrigger подключается дополнительно и не изменяет высоту секции.
